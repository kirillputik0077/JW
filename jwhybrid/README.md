# Jurassic Hybrid (Forge 1.20.1)

## Как получить готовый .jar (без установки чего-либо)
1. Зарегистрируйся на github.com, создай новый репозиторий (Create repository).
2. Нажми "uploading an existing file" и перетащи ВСЁ содержимое этой папки (включая скрытую папку .github).
3. Перейди во вкладку Actions, дождись зелёной галочки (3-5 минут).
4. Открой завершённый запуск, внизу в Artifacts скачай jwhybrid-mod: внутри jwhybrid-forge-1.20.1-1.0.0.jar.
5. Положи .jar в папку mods клиента Minecraft с Forge 1.20.1.

## Игра
- Крафт ДНК-сканера (или он выдаётся при первом входе): железо, стекло, редстоун.
- ПКМ сканером по дикому динозавру = ДНК (слабее цель = больше ДНК, как в JW Alive).
- /jw shop, /jw, /jw create <вид> = создание капсулы за ДНК + монеты (JW The Game).
- ПКМ капсулой по блоку выпускает ручного динозавра, он приносит монеты каждую минуту.
- Корми мясом, чтобы поднимать уровень (до 10). Shift+ПКМ пустой рукой = обратно в капсулу.
